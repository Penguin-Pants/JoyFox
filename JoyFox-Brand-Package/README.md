# JoyFox Angular JF Monogram Brand Package

Production-ready visual identity assets for the JoyFox Firefox and Chrome extension.

## Package structure

```text
master/             SVG masters, marks, wordmarks and lockups
icons/universal/    16–512 px primary app icons
icons/chrome/       Chrome manifest and action PNG icons
icons/firefox/      Firefox manifest and theme-aware toolbar PNG icons
store/chrome/       Chrome Web Store icon, promo images and screenshot template
store/firefox/      Firefox AMO icons and screenshot template
social/             GitHub avatar and social preview
preview/            Brand board and small-size stress test
tokens/             CSS and JSON brand tokens
manifest-snippets/  Ready-to-copy manifest fragments
BRAND-GUIDE.md       Full identity rules
IMPLEMENTATION.md    Browser-specific implementation notes
```

## Primary files

- `master/joyfox-icon-primary.svg`
- `master/joyfox-mark-transparent.svg`

- `master/joyfox-lockup-light-bg.svg`
- `preview/joyfox-brand-board.jpg`

## Important

The JoyFox identity intentionally uses a red/black visual language that feels at home beside JoyClub. It must still remain clearly independent.

Do not use JOYclub's official logo, pixel-heart or Firefox/Mozilla marks as part of the JoyFox identity.
