# JoyFox 1.0.0

The first public release of JoyFox, a local-first Firefox extension that
enhances the JoyClub pages you open. Everything it stores stays in your browser.

## Install

1. Download `joyfox-1.0.0.xpi` below.
2. In Firefox, open `about:addons`, click the gear menu, choose "Install Add-on
   From File" and pick the file.

Firefox 121 or later. The file is signed by Mozilla. JoyFox updates itself: once
a day, Firefox checks this repository's `updates.json` for a newer version.

## What it does

- Marks each ClubMail inbox row by your own contact rule and explains why.
- Private notes and tags for members and events, kept only in your browser.
- Saved member searches, a personal event calendar and shared-preference
  highlights.
- Search over the ClubMail messages you opened, on by default and deleted after
  12 months.
- German and English.

See the README for the full list.

## Disclaimer

Read this before you install JoyFox.

- JoyFox is an independent project. JoyClub does not make, check or support it.
- Nobody has checked whether JoyClub's terms of use allow browser extensions
  like JoyFox. Many platforms forbid automated access. If JoyClub finds that you
  use JoyFox, it can restrict or close your account. Quick Ignore and Delete,
  which clicks JoyClub's own buttons for you, carries the highest risk; it is
  off by default.
- JoyFox stores information about other members (profile facts, your notes and
  tags) only in your browser. You are responsible for how you use and keep that
  information. For private use by one person, EU data protection law very likely
  does not apply (GDPR Article 2(2)(c)), but no lawyer has confirmed this.

## Verify this release

`joyfox-1.0.0-source.zip` holds the source of this release. Building it with
`npm ci`, then `npm run build:firefox` (Node.js 22 or 24) gives exactly the
files in the `.xpi`, apart from Mozilla's signature in `META-INF`. See "Verify a
release" in the README.

## Known limitations

See `docs/known-limitations.md`. Among them: the template picker does not run in
the ClubMail composer on event pages, and JOYCE is not supported yet.
